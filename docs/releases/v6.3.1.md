# V6.3.1 发布验证 / Release validation

发布日期 / Date: 2026-09-05

## 修复 / Fixes

- 解构交付按 V6.3 实际验收、编译和资产账本校验，不再要求旧 6.1/6.0 协议；生成器、蓝图、场景、图片哈希检查保留。
- ZIP 失败有独立状态和错误；已验收 PPT 可直接补打包，不重开构建。
- Windows 系统 Python 可发现已安装的 Codex Node 运行时；外部位图预览失败可对既有 PPT 做一次原生导出，不消耗额外构建。
- 源像素圆角半径在 Windows/Mac 编译成共同可编辑轮廓；未声明半径的旧场景行为不变。
- 中英文 README 使用同一 TEST 蓝图及两种 PPT 的真实原生预览。

Packaging now validates actual V6.3 contracts and ledger assets, while retaining hash checks. ZIP failure/retry is separate from PPT construction. Windows discovers the installed runtime and can recover a failed bitmap preview through native export without rebuilding. Measured corner radii compile into shared editable paths. Both READMEs show the real same-blueprint comparison.

## 边界 / Scope

不改蓝图生成前的源解析、证据写作、提示词与调用次数，不改正式蓝图字节，不改位图裁切与排版，不换母版。位图新增内容仅为锁定后的预览环境/恢复。

Pre-lock source/authoring/ImageGen, immutable blueprints, bitmap crop/layout and the master are unchanged. Bitmap additions only concern post-lock preview recovery.

**Mac 原生渲染未验证 / Mac native rendering unverified:** 共享实现与自动化测试不等于 Mac 视觉验收。保持 `mac_native_render_unverified`，未声称实机验证通过。
