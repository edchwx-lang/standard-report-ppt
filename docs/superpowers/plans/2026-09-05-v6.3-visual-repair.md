## Global Constraints

- 只修改正式蓝图锁定后、`construction_mode: deconstruct` 的路径。
- 蓝图生成前、ImageGen/来源证据/锁定、位图模式、旧版兼容分支和交付包格式不变。
- 母版及五个原占位符不变；主体文字、数字、图表、表格、基础几何可编辑。
- 蓝图主体是视觉最高权威，不用通用矩阵、概念圆圈、统一配色替代。
- 复杂地图/图标/Logo 允许无正文局部素材；派生素材处理不修改锁定蓝图。
- Windows 主修并原生实测；Mac 原则与可实现适配同步，标记 `mac_native_render_unverified`。
- 每工程最多两次实际构建、最多一次视觉修订；故障恢复不得扩大总构建预算。
- 不全局安装、不 push、不 tag，不覆盖原 TEST/S3 工程。已按用户确认执行本地候选修复；commit/合并/推广仍由用户另行决定。
- 实施时使用 `apply_patch`；每个任务先加负例，运行并确认失败原因，再改最少生产代码并验证。提交只暂存任务明确文件，不使用 `git add .`。
