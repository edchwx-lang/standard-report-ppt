# Python reconstruction rules V5.9.1

- Validate the reviewed `reconstruction_contract` before opening either local builder.
- Bind every visible module to stable page-spec `element_id` values.
- Preserve a complete `reviewed_inventory` of independent visual subjects.
- Forbid `native_analytical_element`; native subjects require supported recipes.
- Treat fidelity deviations as warnings that do not trigger a rebuild.
- Bind authoring, alignment, page-spec, and visual-manifest hashes through packaging.

- Treat V5.8.4-aligned UTF-8 runtime manifests as the display/layout source and compile one root generator.
- Preserve the original blueprint wording except recorded factual corrections or uncertain fallbacks.
- Preserve reviewed module topology, series, legends, data labels, annotations, and boxes; Python convenience must not merge or simplify them silently.
- Keep visible text out of runtime helpers.
- Validate executable V5.8 structure before importing `win32com`; emit advisory policy findings without stopping the build.
- Normalize top-level and nested colors before COM assignment.
- Build every chart, table, card, label, line, and arrow as editable native objects.
- Prefer one crop per non-native subject. On failure, use native rebuild, simplified approximation, or omission with a warning.
- Consume the reviewed `crop | native | omit` treatment for every observed visual
  subject. Through V5.9.5, a reviewed page may legitimately have zero crops. In
  V5.9.6, icon, pictogram, logo, map, photo, illustration, device, person, product,
  and flag subjects are mandatory crops; a G1-G3 page containing any such subject
  cannot have zero crops.
- Name skeleton shapes `SKEL_CHAPTER`, `SKEL_TITLE`, `SKEL_CORE`, `SKEL_SOURCE`, and `SKEL_PAGE_NUMBER`.
- Use the template hash and internal safe area; never use PowerPoint editor guides as geometry.
- Open PowerPoint once, save to a temporary PPTX, close PowerPoint, then atomically replace the requested output.
- Copy the immutable ImageGen draft as the formal blueprint, then render the PPT and compare the two for structural fidelity without replacing the blueprint.
- Record every stage in seconds and minutes. Never repeat material parsing. Permit one ImageGen transport retry only when no artifact exists; never regenerate after an image is produced.

Fast mode skips ImageGen and visual crops but uses the same canonical content, chart-first routing, adaptive density, prebuild validation, runtime, rendering, and audits.
