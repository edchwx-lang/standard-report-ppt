# PPT layout and chart rules V5.8.3

## Fixed skeleton

Use the company master, Microsoft YaHei, and the 20/16/12 pt chapter/title/core hierarchy. Chapter, title, and first core bullet share one left anchor within 0.02 inches. Use 0.4 cm, 1.5 cm, and 2.7 cm top positions. Keep at least 0.06 inches between title and core. Use no decorative line above the chapter and no separator above the source.

PowerPoint editor guides are not geometry inputs. Read the real slide size and use the V5.8 internal safe area; do not recreate deleted guides. Skeleton deviations are warnings unless they make the page unreadable or prevent PowerPoint execution.

## Visual-first, chart-first decision table

| Observable evidence | Primary expression |
|---|---|
| Three or more ordered periods | Line for continuity; column for discrete snapshots; combo only with a second comparable series or metric |
| Three or more comparable categories with one unit | Horizontal bar, grouped bar, or column chart |
| Parts of one whole | Donut composition |
| Comparable objects across numeric metrics | Grouped horizontal bars |
| Technical structure, material composition, or equipment principle | Annotated structure diagram or subject illustration |
| Industry chain or upstream/downstream relation | Chain with meaningful visual nodes |
| Object differences | Image-text comparison |
| Exact lookup over many objects/dimensions | Matrix or table |
| Ordered operational stages | Editable flow |
| Independent qualitative points | Parallel narrative modules with visual anchors; no fake numbering or arrows |
| Qualitative narrative | Prose with a relevant visual anchor |
| Real non-stage cause-effect evidence | Causal flow |

Chartable numeric pages receive a warning when a matrix replaces a more legible chart. A matrix remains valid when exact lookup matters, units are incompatible, or continuity would be misleading. Python implementation convenience must not affect the selected expression.

## Adaptive density

Target about 70% of the approved dense reference's effective information load without copying a fixed layout. Use 60-96% body occupancy for data-rich pages, 55-94% for mixed pages, and 48-90% for qualitative pages. These are soft evidence-capacity bands; deviations are warnings, not a required number of modules.

Matrices, flows, and card grids are not defaults. Let the evidence select charts, annotated structures, visual chains, image-text comparisons, lookup tables, true processes, or narrative modules with a visual anchor. Supporting raster visuals have no numeric quota.

## Common layouts

- Large chart plus interpretation.
- Annotated subject or structure plus evidence labels.
- Visual-node chain plus value explanation.
- Image-text comparison with matched evidence.
- Trend chart plus metric strip and implications.
- Lookup matrix when precise values dominate.
- Parallel narrative modules or a causal flow only when supported by evidence.

Do not automatically number parallel regions. Number only a real sequence, stage, rank, or method. Do not force a top-three/bottom-four structure.

## Blueprint responsibility

The immutable ImageGen result is the formal blueprint and visual benchmark. Canonical manifests provide the exact text to Python. Python locks final typography, wrapping, coordinates, and editability; blueprint text differences and PPT structural-fidelity differences are warnings.

## V5.7 compatibility

Schema 5.7 keeps the historical analytical canvas: Keep charts, tables, matrices, and flows as the primary evidence-bearing body. Use small pictograms, supplied logos, flags, or bounded schematic accents; optional accents occupy 6-12% of the body area and remain in a reserved icon lane. This band is not used by V5.8.
